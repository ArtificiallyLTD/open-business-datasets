# Y Combinator companies

Every company listed in the [Y Combinator company directory](https://www.ycombinator.com/companies), from the first batch in 2005 to the latest. Company-level facts only; founder names are left out.

- **Rows:** 6,391
- **Files:** [`yc-companies.csv`](yc-companies.csv) and [`yc-companies.json`](yc-companies.json)
- **Refreshed:** weekly, every Monday

## Columns

| Column | Meaning |
| --- | --- |
| `ycId` | YC directory ID |
| `name` | Company name |
| `website` | Company website |
| `oneLiner` | One-line description from YC |
| `batch` | YC batch, e.g. Winter 2024 |
| `status` | Active, Acquired, Inactive or Public |
| `stage` | Early, Growth and similar |
| `industry` | Top-level industry |
| `subindustry` | Industry path, e.g. B2B -> Productivity |
| `tags` | YC tags, separated by "; " |
| `location` | Headquarters location(s) |
| `country` | Country code |
| `teamSize` | Team size reported to YC |
| `yearFounded` | Year founded, when listed |
| `isHiring` | Has open jobs on Work at a Startup |
| `topCompany` | Listed as a YC top company |
| `linkedin` | Company LinkedIn page, when listed |
| `ycUrl` | Company page on ycombinator.com |

## Fresher or filtered data

Built with the [Y Combinator Scraper](https://apify.com/artificially/ycombinator-scraper) on Apify. Run it yourself to add founders, open jobs and full social links, or monitor for new companies.
